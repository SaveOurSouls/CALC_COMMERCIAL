# CALC_COMMERCIAL

Расчёт коммерческих предложений.

## Кабельные книги (КБ) и БД.ОП

В папке [`apps-script/`](apps-script/) — Google Apps Script для книги с техкартами:

- Sidebar для быстрого набора операций и копирования строк
- Отказ от пар листов `TL_КБ1` … `TL_КБ20` (динамические списки и FILTER)
- Расчёт колонок **8** (время) и **Цена** по типу операции

Инструкция: [`docs/KB_APPS_SCRIPT.md`](docs/KB_APPS_SCRIPT.md).
