# Оптимизация кабельных книг (КБ) без листов TL_КБ

Решение для книги [CALC_COMMERCIAL](https://docs.google.com/spreadsheets/d/1Y7Uj9ekeRfOcM7Eyl19ttamWjzqzUVl47X4DGHUG7fE/edit): быстрый набор операций, отказ от 20+ пар `TL_КБ*`, расчёт колонок **8** (время) и **Цена**.

## Установка Apps Script

1. Откройте таблицу → **Расширения** → **Apps Script**.
2. Создайте файлы из папки `apps-script/` этого репозитория (или привяжите проект через [clasp](https://github.com/google/clasp)).
3. В `Config.gs` сверьте:
   - имя листа `БД.ОП`;
   - заголовки колонок с первой строкой листов КБ и БД.ОП;
   - при необходимости замените `'8'` в `kb.timeTotal` на заголовок колонки, если в строке 1 не цифра `8`.
4. Сохраните, обновите таблицу (F5). В меню появится **Техкарта КБ**.

## 1. Быстрый набор (Sidebar)

**Техкарта КБ → Панель быстрого набора**

- Выбор листа КБ1…КБN (любое количество листов по шаблону `КБ\d+`, без новых TL).
- Фильтр операций по эскизу и поиск по номеру.
- Поля N, L, OP и вставка нескольких одинаковых строк.
- **Скопировать последнюю строку** — для серии проводов разной длины/цвета: скопировать строку, поменять только L или N.

Подтягивание полей из БД.ОП и пересчёт времени/цены выполняются скриптом при вставке.

## 2. Уход от TL_КБ1 … TL_КБ20

### Вариант A (рекомендуется): Sidebar + обновление списка при выборе эскиза

Скрипт `onEdit` при изменении **Эскиз проекта** подставляет в **Номер** актуальный список операций из БД.ОП для этой строки. Отдельные листы `TL_КБ*` не нужны.

### Вариант B: одна формула на все строки (без скрипта для списка)

В **Данные → Проверка данных** для колонки «Номер» (диапазон со 2-й строки) укажите диапазон:

```excel
=SORT(UNIQUE(FILTER(БД.ОП!$B:$B,БД.ОП!$A:$A=$B2)))
```

Замените `$A` / `$B` на буквы колонок **Название** и **Номер** в БД.ОП; `$B2` — ячейка **Эскиз проекта** в той же строке листа КБ. Формула относительная: для строки 10 будет `$B10`. Один шаблон на все листы КБ1…КБ40.

Меню **Техкарта КБ → Миграция: убрать TL_КБ** помогает массово проставить валидацию на активном листе (после ввода букв колонок БД.ОП).

Старые листы `TL_*` можно скрыть или удалить после проверки.

## 3. Расчёт колонок 8 и Цена

### Логика (как в ТЗ)

| Тип операции | Время (кол. 8), сек | Цена |
|--------------|---------------------|------|
| **Погонный** | `(1/Скорость проката + Скорость работы инструмента × Кол-во операций инструмента) × L × N` | `время × Уд.Цена МШ + время × Уд.Цена ЧЛ_МАГ` |
| **Переменный**, **Статичный** | `Время Чел, сек/оп; сек/м × N` | `время × ЧЛ_МАГ + Время машины × N × Уд.Цена МШ` |

### Скрипт

**Техкарта КБ → Пересчитать время и цену** — по всем строкам активного листа КБ.  
Пересчёт также срабатывает при изменении N, L или Номера (`onEdit`).

### Формулы в ячейках (альтернатива)

Подставьте буквы колонок вашего листа КБ (пример: тип в `G`, N в `E`, L в `D`, скорости подтянуты из БД.ОП в `H:K`):

**Время (колонка 8):**

```excel
=IF(G2="Погонный",(1/H2+I2*J2)*D2*E2,IF(OR(G2="Переменный",G2="Статичный"),K2*E2,""))
```

**Цена:**

```excel
=IF(G2="Погонный",R2*M2+R2*N2,IF(OR(G2="Переменный",G2="Статичный"),R2*O2+P2*E2*M2,""))
```

Где `R2` — ячейка времени (кол. 8), `M2` — Уд.Цена МШ, `N2` — Уд.Цена ЧЛ_МАГ, `O2` — ЧЛ_МАГ, `P2` — Время машины (подставьте свои буквы).

Функции `buildTimeFormulaTemplate_` / `buildPriceFormulaTemplate_` в `Calculations.gs` генерируют шаблон по объекту с буквами колонок.

## Масштабирование КБ1…КБN

- Добавляйте листы `КБ21`, `КБ22`, … с **той же строкой заголовков**, что у КБ1.
- Не создавайте новые `TL_КБ*`.
- Sidebar и `onEdit` распознают любой лист по имени `КБ` + цифры.

## Настройка после копирования

| Проблема | Действие |
|----------|----------|
| Ошибка «нет колонки …» | Исправьте заголовки в `Config.gs` |
| Пустой список «Номер» | Проверьте совпадение **Эскиз проекта** с **Название** в БД.ОП |
| Неверное время | Проверьте **Тип операции** и единицы скоростей в БД.ОП |
