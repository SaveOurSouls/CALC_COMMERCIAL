# Оптимизация кабельных книг (КБ) без листов TL_КБ

## Структура колонок (как в вашей книге)

### Лист КБ — заголовки в **строке 4**, данные с **строки 5**

| Колонка | Заголовок |
|---------|-----------|
| A | Эскиз проекта |
| B | Номер |
| C | Комплектующая |
| D | N |
| E | L |
| F | OP |
| G | SUMM |
| H | Требования к задаче |
| I | **6** ← БД.ОП «Время подготовки, сек» |
| J | **7** ← БД.ОП «Расход на настройку м; шт;» |
| K | **8** ← суммарное время операции (расчёт) |
| L | **9** ← суммарное время машины (расчёт) |
| M | 10 (не используется, можно удалить) |
| N | **Цена** |
| O | Уд.Цена ЧЛ, сек |
| P | Уд.Цена МШ, сек |
| Q | Тип операции |

### Лист БД.ОП — строка заголовков определяется **автоматически** (сканирование строк 1–15)

Ожидаются колонки **Номер** и **Название** (или синоним из `dbAliases` в `Config.gs`). Данные — со следующей строки после заголовков.

| Колонка | Заголовок |
|---------|-----------|
| A | Номер |
| B | Название |
| C | Полуфабрикат |
| … | (см. `Config.gs` → `db`) |

**Связь:** на КБ поле **Эскиз проекта** = в БД.ОП **Название**; **Номер** = **Номер**.

### Колонки 6–9

| КБ | Источник |
|----|----------|
| **6** | БД.ОП «Время подготовки, сек» |
| **7** | БД.ОП «Расход на настройку м; шт;» |
| **8** | Расчёт: суммарное время операции |
| **9** | Расчёт: суммарное время машины |
| **10** | Не используется |

Одинаковые по имени заголовки (Уд.Цена ЧЛ, Уд.Цена МШ, Тип операции) копируются из БД.ОП автоматически.

## Установка Apps Script

1. **Расширения → Apps Script**.
2. Скопируйте только **`.gs`** и **`Sidebar.html`** из `apps-script/`.
3. Сохраните, обновите таблицу — меню **Техкарта КБ**.

## Список «Номер» без TL_КБ

Проверка данных для колонки B, с строки 5:

```excel
=SORT(UNIQUE(FILTER(БД.ОП!$A:$A,БД.ОП!$B:$B=$A5)))
```

## Расчёт колонок 8, 9 и «Цена»

| Тип | Кол. 8 (суммарное время операции) | Кол. 9 (время машины) | Цена |
|-----|-----------------------------------|------------------------|------|
| **Погонный** | `(1/Скорость проката + Скорость инструмента × Кол-во оп.) × L × N` | то же, что кол. 8 | `8 × Уд.Цена МШ + 8 × Уд.Цена ЧЛ_МАГ` |
| **Переменный / Статичный** | `Время Чел × N` | `Время машины × N` | `8 × Уд.Цена ЧЛ_МАГ + 9 × Уд.Цена МШ` |

Скрипт пишет результат в **K** (8) и **L** (9). Пересчёт: **Техкарта КБ → Пересчитать время и цену** или при изменении N, L, Номера.

## Справочник + плавающая очередь

| Меню | Назначение |
|------|------------|
| **Справочник (боковая панель)** | Эскиз, операция, N, L → **+ В очередь**; **Полуфабрикат** — тип + артикул → **+ Полуфабрикат в очередь** |
| **Очередь операций (плавающее окно)** | Список, порядок, **Вставить всё**; блок **Набор полуфабриката** (группа + артикул → **Записать** / загрузить / удалить); **+ Добавить лист** |
| **Сохранить активный лист в шаблон КБ** | То же из меню: копия с формулами на вкладку `КБ.ШАБЛ.1`, `КБ.ШАБЛ.2`, … |

Очередь на сервере. Скриптовый пересчёт кол. 8, 9, Цена отключён (`kbEnableScriptRecalc: false`). Шаблоны — `КБ.ШАБЛ.N`. **Наборы полуфабрикатов** — лист `КБ.ПРЕСЕТЫ` (скрытый, в той же книге; перезапись по паре группа+артикул).

### Обязательные файлы в Apps Script

| Тип | Имя |
|-----|-----|
| HTML | `Sidebar`, `QueueDialog` |
| Script | `Code`, `Config`, `QueueStore`, `SemifinishedPresets`, … |

Если в окне очереди виден код `.gs` — в проект ошибочно вставлен `QueueStore` вместо `QueueDialog.html`.
После «Записать» в справочнике нажмите **↻ Обновить список полуфабрикатов** (или подождите ~12 с).

### Структурированная таблица

- Вставка **на место выделенной строки** (`insertRowsBefore` одним блоком; запись напрямую в строку, без scratch под таблицей).
- Колонки **8, 9, Цена** — формулы таблицы (`kbSkipWriteCalculatedInTable: true` по умолчанию).
