# Оптимизация кабельных книг (КБ) без листов TL_КБ

## Структура колонок (как в вашей книге)

### Лист КБ — заголовки в **строке 4**, данные с **строки 5**

| Колонка | Заголовок |
|---------|-----------|
| A | Эскиз проекта |
| B | Номер |
| C | Комплектующая |
| D | N |
| E | L |
| F | OP |
| G | SUMM |
| H | Требования к задаче |
| I | 6 |
| J | 7 |
| K | **8** (время операции, сек) |
| L | 9 |
| M | 10 |
| N | **Цена** |
| O | Уд.Цена ЧЛ, сек |
| P | Уд.Цена МШ, сек |
| Q | Тип операции |

### Лист БД.ОП — заголовки в **строке 1**, данные с **строки 2**

| Колонка | Заголовок |
|---------|-----------|
| A | Номер |
| B | Название |
| C | Полуфабрикат |
| … | (см. `Config.gs` → `db`) |

**Связь:** на КБ поле **Эскиз проекта** = в БД.ОП **Название**; **Номер** = **Номер**.

### Подтягивание в колонки 6, 7, 9, 10

В `Config.gs` → `kbDbPull` (при необходимости поправьте):

| КБ | БД.ОП |
|----|--------|
| 6 | Время Чел, сек/оп; сек/м |
| 7 | Время машины, сек/оп; сек/м |
| 9 | Скорость проката |
| 10 | Скорость работы инструмента |

Одинаковые по имени заголовки (Уд.Цена ЧЛ, Уд.Цена МШ, Тип операции) копируются автоматически.

## Установка Apps Script

1. **Расширения → Apps Script**.
2. Скопируйте только **`.gs`** и **`Sidebar.html`** из `apps-script/`.
3. Сохраните, обновите таблицу — меню **Техкарта КБ**.

## Список «Номер» без TL_КБ

Проверка данных для колонки B, с строки 5:

```excel
=SORT(UNIQUE(FILTER(БД.ОП!$A:$A,БД.ОП!$B:$B=$A5)))
```

## Расчёт «8» и «Цена»

| Тип | Время (K) | Цена (N) |
|-----|-----------|----------|
| Погонный | `(1/скорость_проката+скорость_инструмента×кол-во)×L×N` | `время×Уд.Цена МШ + время×Уд.Цена ЧЛ_МАГ` |
| Переменный / Статичный | `Время Чел × N` | `время×Уд.Цена ЧЛ_МАГ + Время машины×N×Уд.Цена МШ` |

Скрипт берёт коэффициенты из **БД.ОП**; в K и N пишет результат. Либо **Техкарта КБ → Пересчитать**.

**Формула в K5 (если I/J/M уже подтянуты из БД):**

```excel
=IF($Q5="Погонный",(1/L5+M5)*$E5*$D5,IF(OR($Q5="Переменный",$Q5="Статичный"),$I5*$D5,""))
```

**Формула в N5:**

```excel
=IF($Q5="Погонный",$K5*$P5+$K5*INDEX(БД.ОП!$P:$P,MATCH(1,(БД.ОП!$B:$B=$A5)*(БД.ОП!$A:$A=$B5),0)),IF(OR($Q5="Переменный",$Q5="Статичный"),$K5*INDEX(БД.ОП!$P:$P,MATCH(1,(БД.ОП!$B:$B=$A5)*(БД.ОП!$A:$A=$B5),0))+$J5*$D5*$P5,""))
```

(Упростите через скрипт или фиксированные O/P, если цены уже на строке.)
